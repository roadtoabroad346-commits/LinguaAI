# LinguaAI — Streamlit для двухнедельного исследования

Приложение готово для локального запуска, интерфейс на казахском. Это отдельный дашборд исследования, он не подключается к сайту LinguaAI автоматически. Баллы и журнал вводятся вручную или загружаются из CSV. Онлайн-развёртывание не выполнялось.

## Быстрый запуск

Нужны Python 3.11 или новее, компьютер и интернет для первой установки зависимостей. Открой терминал в этой папке:

```bash
python -m venv .venv
```

Windows:

```powershell
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m streamlit run app.py --server.address 127.0.0.1
```

macOS или Linux:

```bash
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py --server.address 127.0.0.1
```

Открой адрес, который покажет терминал, обычно http://localhost:8501. Повторный запуск требует только последней команды. Включён сбор только локально; приложение не публикуется автоматически. Если установлен python3, используй его вместо python при создании окружения.

## Работа с результатами

1. В левом меню выбери «Модельдік зерттеу нәтижелері» для примера или «Нақты өлшеулер» для настоящих измерений. В реальном шаблоне 10 кодов P001–P010, уровни и все баллы пустые.
2. На вкладке «Өлшеулерді енгізу» внеси начальный уровень по отдельному placement test/оценке учителя, начальный тест, тест дня 7 и дня 14. Нажми «Баллдарды талдауға қолдану».
3. Сразу скачай CSV. Правки живут только в текущей сессии браузера, после перезапуска могут исчезнуть. В следующий раз загрузи сохранённый CSV слева.
4. Журнал за 14 дней заполни в data/daily_real_template.csv, сохраняя заголовки и коды. Загрузи его через «Күнделікті белсенділік CSV». Неизмеренные значения оставляй пустыми. Известное отсутствие занятий обозначай 0 минутами.
5. Выбирай коды участников в левом меню. На вкладках результатов видны парные изменения теста, дневная активность и индивидуальный профиль.
6. На вкладке «Зерттеуге экспорт» нажми «Графиктер архивін дайындау», затем скачай архив PNG/SVG/PDF. Экспорт учитывает выбранных участников и текущие данные. Пока измерений нет, графиков с результатами нет.

## Что считается

Начальный и финальный средние считаются по одному и тому же набору завершённых пар. Для графика трёх контрольных точек используются только участники со всеми тремя тестами. Пропуски не становятся нулём. Баллы ограничены общей шкалой test_max. При нулевом начальном среднем относительный процент не рассчитывается. CEFR из короткого теста не выводится. Ежедневная точность — сумма правильных ответов / сумма попыток, это другой показатель, не контрольный тест.

В исходном исследовании планировался четырёхнедельный пилот. Этот двухнедельный трекер — дополнительный краткий этап или пример процедуры, а не замена заявленной программы.

## Проверка

```bash
python -m unittest -v test_progress.py
```

При подготовке проверены 8 тестов расчётов и экспорта, запуск через Streamlit AppTest, переключение demo/real, пустой фильтр, выбор одного профиля и экспорт. Среда проверки Streamlit 1.66.1, pandas 2.2.3; требования включены. Вёрстка браузера на разных устройствах отдельно не проверялась.

Не приписывай им демонстрационные уровни и баллы. Для публичных приложений и научных иллюстраций используй коды; соответствие имён храни отдельно.
