# LinguaAI — публичная инфографика исследования

Streamlit-приложение показывает результаты 14-дневного наблюдения десяти учеников. Интерфейс оптимизирован для просмотра жюри с телефона по QR-коду.

Публичный адрес: https://linguaai-research-dashboard.onrender.com/

## Содержание

- общая динамика результатов на 0-й, 7-й и 14-й дни;
- индивидуальный рост каждого ученика;
- тепловая карта учебных минут за 14 дней;
- сравнение первой и второй недели;
- общая точность упражнений;
- индивидуальные профили учеников;
- структура анонимной анкеты Google Forms.

## Исходные данные

`data/progress_actual.csv` содержит уровни, три тестовых результата, количество заданий, ответов и правильных ответов. `data/daily_actual.csv` содержит учебные минуты по каждому из 14 дней. Данные внесены из предоставленной исследователем таблицы. Тестовая шкала — 25 баллов.

Файл с экспортом реальных ответов Google Forms пока не добавлен. Поэтому приложение не показывает вымышленные мнения или проценты опроса.

## Локальный запуск

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py --server.address 127.0.0.1
```

В Windows используй `.venv\Scripts\python` вместо `.venv/bin/python`.
