# Публикация и QR

В этой папке подготовлен render.yaml для Python Web Service с бесплатным планом. Файлы данной папки должны быть в корне репозитория. Не добавляй именной список из родительской папки.

Публикация требует подключённого аккаунта Render и доступного ему репозитория. Этот архив сам по себе не создаёт публичную ссылку. Фактический статус публикации сообщается отдельно после проверки развёртывания.

После развёртывания приложение получает свой действующий адрес из RENDER_EXTERNAL_URL и показывает QR в боковой панели. Его можно скачать в PNG и SVG. Для другого хостинга задай PUBLIC_APP_URL равным проверенному публичному HTTPS-адресу приложения.

В QR кодируется только адрес, предоставленный хостингом или владельцем приложения. Локальные адреса в QR не подставляются. Перед печатью нужно проверить ссылку с телефона через мобильный интернет и сравнить содержимое QR с адресом приложения.

Бесплатный сервис может запускаться медленнее после простоя. Перед выступлением открой приложение заранее. Сессия редактирования баллов не заменяет постоянную базу: результаты сохраняются скачиванием CSV.

Исходники справки: https://render.com/docs/blueprint-spec и https://render.com/docs/environment-variables.
